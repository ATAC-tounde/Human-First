      CONTINUITÉ · SAUVEGARDE PRIVÉE

      Un coffre chiffré, sans compte.

      Sauvegarde ton parcours dans un fichier chiffré ou, volontairement, sur cet appareil. Rien n'est synchronisé en ligne.

      Choisis une phrase secrète longue et unique (12 caractères minimum). Si tu l'oublies, nous ne pourrons pas récupérer ta sauvegarde. Conserve aussi une copie du fichier hors de cet appareil. Les données de navigation et métadonnées peuvent rester visibles pour l'utilisateur de ce navigateur.

      Cette sauvegarde n'est ni automatique ni certifiée. Le stockage du navigateur peut être effacé par le système : garde une copie externe.

      V1.2 · SYNCHRONISATION CHIFFRÉE FACULTATIVE

      Une copie distante, sous ton contrôle.

      Pilote expérimental : seule une sauvegarde déjà chiffrée peut être envoyée sur un serveur configuré. Aucun compte ni synchronisation automatique.

      Le code de jumelage donne accès à la sauvegarde chiffrée et permet de la remplacer ou de l’effacer. Ne le partage pas. La phrase secrète du chiffrement est différente. Si tu perds les deux, aucune récupération n’est possible. Pas de synchronisation si le serveur est désactivé.

      Vérification du serveur de sauvegarde…

      Aucun code de jumelage n’est enregistré sur l’appareil par HUMAN FIRST. Cette version pilote nécessite un serveur Node unique avec stockage durable, sous HTTPS. Elle est désactivée par défaut, y compris sur Vercel.
